# Contributing

Describe the problem, expected behavior and a minimal fictional example. Explain changes and how you checked them.

Keep shared rules in CLAUDE.md, settings in Workspace Config.md and workflow-specific instructions in each skill. Document new dependencies in docs/SETUP.md.

Use synthetic data only. Do not include private tickets, URLs, personal records, credentials or session identifiers. Check screenshots and metadata too.

Run `python3 scripts/validate_workspace.py` before submitting. Claim connector compatibility only for environments actually tested.
