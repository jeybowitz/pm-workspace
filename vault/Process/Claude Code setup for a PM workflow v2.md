# How the workspace works

The PM and assistant share Markdown sources, decisions and drafts. Obsidian is optional.

1. Record verified current behavior in Reference/ and source notes in Research/ or Meetings/.
2. Draft a feature in Discovery/ using the template. Keep it there throughout its lifecycle.
3. Resolve scope and questions with the PM; record evidence and decisions in AI Context.
4. The PM marks the document Spec ready when the gate in Vault Structure is met.
5. Prepare local drafts in Jira/. Review assumptions and dependencies before a separately authorized publication.

The Jira skill permits explicit single-story drafts and technical tasks without an epic document. It does not publish tickets.

CLAUDE.md defines shared rules. Workspace Config.md supplies local context. Reference/ holds current behavior; Discovery/ holds proposals. Skills provide optional procedures. Historical memory cannot override current instructions.

The repository README and docs/SETUP.md explain installation. examples/room-booking is a fictional walkthrough, with no claimed production evidence or results.
